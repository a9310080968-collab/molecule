# MOLECULE × TSUM MARKETING

Кликабельный демонстрационный прототип единого визуального рабочего пространства для руководителя и исполнителя.

## Демонстрационные учетные записи

- руководитель — Виктория Соколова (`manager@tsum.demo`);
- исполнитель — Елена Крылова (`employee@tsum.demo`).

Пароль в прототипе не используется: роль выбирается на стартовом экране. Из активной сессии учетную запись можно сменить через кнопку в правом верхнем углу.

## Основная логика

Приложение состоит из одного полноэкранного полотна MOLECULE. Центральный объект — выбранный сотрудник. Вокруг него автоматически строятся:

- функции сотрудника;
- бизнес-процессы и поставленные руководителем задачи;
- смежные команды;
- результат и KPI;
- системные сигналы об отклонениях.

Каждый объект кликабелен и свободно перемещается по полотну, а связи следуют за нодами. Детали не перегружают карту и открываются в отдельных рабочих окнах поверх полотна.

## Роли и права

Руководитель видит карты сотрудников и может:

- добавлять ноды и соединять их связями;
- редактировать описание ноды и прикладывать файлы;
- ставить новые задачи с постановщиком и дедлайном;
- принимать задачу или возвращать ее со статусом «Не принято»;
- задавать вопросы и отвечать в обсуждении каждой задачи.

Исполнитель видит только свою рабочую карту и список своих задач. Он может переводить задачу в статусы «Не в работе», «В работе» и «Передано на проверку», а также вести обсуждение с руководителем. Редактирование структуры карты, описаний и файлов для исполнителя закрыто.

## Рабочие окна

- «Задачи» — полный рабочий план, постановщик, дедлайн, прогресс и сигналы;
- «Аналитика» — загрузка, своевременность, межкомандные связи и диагностика;
- «Оптимизация» — проверяемые возможности улучшения процессов без автоматических кадровых решений;
- «Расходы» — условная стоимость позиции и распределение ресурса по процессам;
- окно бизнес-процесса — полный маршрут от сотрудника и функции до результата и KPI;
- выбор сотрудника — поиск и фильтрация всех 88 демонстрационных сотрудников.

Руководитель может поставить сотруднику новую задачу с обязательным дедлайном. Если задач не было, после постановки соответствующий сигнал автоматически исчезает, а процесс появляется на карте. Изменения ролей, статусов, вопросов и карты сохраняются внутри текущей демонстрационной сессии и сбрасываются при перезагрузке страницы.

## Запуск

```powershell
pnpm install
pnpm exec vite --host 127.0.0.1 --port 4174
```

Проверка production-сборки:

```powershell
pnpm run build
```

## Изоляция

Прототип развивается в ветке `codex/tsum-marketing-prototype` и отдельном Git worktree. Рабочая Molecule в ветке `main` не изменяется.

Все имена, показатели, бюджеты и организационная структура являются демонстрационными.
