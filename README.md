# 2D-карта документации ЖК Сириус

Интерактивная демоверсия веб-приложения для инвесторского показа: проектная документация представлена как живая 2D-молекула из разделов и рабочих документов. Центральная нода показывает готовность проекта через жидкостное заполнение, средние ноды отражают согласование ГИП, а малые ноды подсвечиваются по типам файлов.

## Запуск

```bash
npm install
npm run dev
```

После запуска Vite откройте локальный адрес вида `http://localhost:5173/`.

## Стек

- React + TypeScript + Vite
- SVG/HTML 2D-карта поверх sci-fi интерфейса
- Tailwind CSS
- Моковые данные внутри frontend-кода, backend не требуется

## Возможности демо

- Одинарный клик выбирает ноду и показывает параметры справа.
- Двойной клик по малой ноде открывает mock-просмотр документа.
- Ноды можно перетаскивать; связи тянутся как резина и автоматические связи рвутся только после большого расстояния.
- Средние ноды можно двигать независимо: связи с вложенными документами не рвутся от движения раздела.
- Малые ноды можно переносить к разделам, внутрь разделов или к другим малым нодам.
- Shift + клик выбирает несколько нод, после чего их можно переносить группой.
- Файлы и ссылки можно перетаскивать прямо в карту: появляется новая малая нода.
- PDF и TXT показываются в предпросмотре, DOC/DOCX, Excel и PowerPoint открываются через браузерный/системный просмотр.
- Любую нецентральную ноду можно переключить между ролью малой и средней в правой панели.
- Связи кликабельны: в правой панели можно описать смысл связи, закрепить ее, удалить или начать ручное протягивание.
- Ручные и закрепленные связи не рвутся от расстояния.
- Проценты отображаются только на центральной ноде. Средние ноды серые до согласования, а согласованные получают отдельный фиолетовый цвет.
- Цвет малых нод зависит от типа файла: TXT белый, DOC/DOCX синий, XLS/XLSX зеленый, PDF красный, PPT/PPTX желтый.
- Раздел можно отправить на согласование ГИП; в демо ГИП может согласовать все документы, часть документов или отклонить пакет.
- При частичном согласовании несогласованные документы выносятся из раздела обратно в рабочую зону.
- Нижняя панель содержит Undo/Redo, нормализацию структуры, сброс вида, фокус на выбранной ноде и общий размер шрифта.
- Пункты левого меню открывают демо-разделы с будущим наполнением.
