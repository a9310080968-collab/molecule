# MOLECULE × TSUM MARKETING

Кликабельный демонстрационный прототип для руководителя маркетингового департамента крупного luxury department store.

Прототип отвечает на пять управленческих вопросов:

1. Как загружены 12 команд и 88 сотрудников?
2. Где функции дублируются или не связаны с измеримым результатом?
3. Какие процессы зависают на согласованиях и от кого они зависят?
4. Сколько маркетинг тратит по категориям и какой результат получает?
5. Какие optimization opportunities стоит проверить руководителю?

Система намеренно не предлагает «кого уволить». Она показывает наблюдаемые факты, зависимости и проверяемые гипотезы для управленческого решения.

## Что кликается

- KPI на обзорном экране ведут в соответствующий срез данных;
- карточки 12 команд открывают показатели команды и список сотрудников;
- список 88 сотрудников фильтруется по загрузке, критичности и команде;
- карточка сотрудника показывает стоимость позиции, функции, загрузку и влияние;
- два сквозных процесса позволяют выбирать каждый этап маршрута;
- вкладка «Молекула процессов» позволяет выбрать любого из 88 сотрудников и увидеть его руководителя, задачи, функции, взаимодействия, результаты и KPI;
- по умолчанию руководитель видит только главное отклонение, рекомендуемое действие и три ключевых показателя; карта и полный рабочий план открываются отдельными вкладками;
- автодиагностика поднимает алармы, если задач нет, задача зациклена без дедлайна, просрочена, заблокирована или поставлена не руководителем;
- руководитель может поставить новую задачу с обязательным дедлайном прямо из карты; для сотрудника без задач это сразу снимает соответствующий аларм;
- расходы раскрываются по категориям и командам;
- 8 зон оптимизации открывают доказательства и следующий управленческий шаг.

## Запуск

```powershell
pnpm install
pnpm run dev -- --host 127.0.0.1
```

Проверка production-сборки:

```powershell
pnpm run build
```

## Изоляция

Прототип развивается в ветке `codex/tsum-marketing-prototype` и отдельном Git worktree. Он не меняет рабочие файлы основной Molecule в ветке `main`.

Все имена, показатели, бюджеты и оргструктура в прототипе демонстрационные.
